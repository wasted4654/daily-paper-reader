## 摘要
多智能体交互式世界模型不仅应生成一致的观测结果，还应维护跨智能体持久存在并随视角演化的世界状态。现有的自回归视频扩散流水线将观测历史作为条件上下文进行传递，这使得在多智能体和多视角设置下难以维护共享状态。我们提出了 WorldWeaver (W^2)，这是一种流式多智能体视频扩散模型，它通过跨智能体世界状态寄存器增强了推演过程：这些寄存器是可学习的标记（tokens），用于存储共享的世界信息、跟踪单个智能体的状态，并在每个生成的块（chunk）之后进行动态更新。我们利用涵盖单个智能体状态、包括鸟瞰图在内的全局状态视图以及场景文本的监督信号来约束这些寄存器。我们通过混合 Transformer（Mixture-of-Transformers）设计进一步改进了架构，该设计为世界状态建模和视觉帧建模使用独立的权重。在双智能体 Minecraft 视频生成方面的广泛实验表明，显式的世界状态建模提高了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

*   **核心问题**：在多智能体交互式世界模型中，如何确保不同智能体在共享世界中的观测结果具有逻辑和几何一致性。

    1.  **状态难以维持**：模型必须在每一步生成中重新推断世界信息，缺乏显式的、持久的世界状态表示。

### 2. 方法论
论文提出了 **WorldWeaver ($W^2$)**，其核心思想是在生成过程中引入“世界状态寄存器（World State Registers, WSR）”。

*   **核心思想**：使用一组可学习的 Token 作为寄存器，在自回归推演（Rollout）过程中动态存储和更新共享的世界信息。
*   **关键技术细节**：
    *   **世界状态寄存器 (WSR)**：这些 Token 与视频帧 Token 交织在一起。在生成每一帧后，模型会根据新生成的观测和之前的寄存器状态更新 WSR。
    *   **混合 Transformer (MoT) 架构**：为了避免视觉生成任务与状态建模任务之间的权重冲突，模型采用 MoT 设计，为 WSR 分支和视觉帧分支分配独立的权重，但在注意力机制中保持交互。
    *   **多模态监督信号**：通过三个维度的信号对寄存器进行显式引导：
        1.  **智能体状态**：预测位置、速度、朝向。
        2.  **全局几何 (BEV)**：预测鸟瞰图特征（基于 DINOv2）。
        3.  **语义描述**：预测场景文本描述（基于 Llama-3.2）。
*   **训练流程（三阶段）**：
    1.  **双向训练**：训练一个具有全局上下文的教师模型，学习跨智能体的场景结构。
    2.  **因果训练**：引入 WSR 和因果掩码，训练学生模型进行自回归生成，并加入状态监督。
    3.  **Self-Forcing 训练**：让模型在自身生成的预测上进行推演，通过分布匹配（DMD）减少长程生成的漂移。

### 7. 优点（亮点）
*   **创新性架构**：将“寄存器”概念引入扩散模型，解决了长程推演中的状态丢失问题。
*   **可解释性**：通过解码寄存器中的状态（如 BEV 或文本），可以直观地观察模型内部对世界的理解，而不仅仅是看像素输出。
*   **多智能体协同**：提供了一种优雅的方案来处理多视角下“同物不同影”的一致性难题。

### 8. 不足与局限
*   **环境局限性**：实验主要局限于 Minecraft 这种网格化、相对简单的模拟环境，在真实世界复杂场景下的泛化能力有待验证。

*   **智能体规模**：实验仅展示了双智能体场景，尚未验证在更大规模（如 10+ 智能体）下的计算开销和状态冲突问题。
