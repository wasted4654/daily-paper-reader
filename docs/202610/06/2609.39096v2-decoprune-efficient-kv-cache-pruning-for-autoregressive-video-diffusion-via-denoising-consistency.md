## 摘要
自回归视频扩散支持流式生成和交互式控制，但其 KV 缓存（KV cache）会随着生成的历史内容而持续增长。现有的压缩策略要么使用固定窗口丢弃历史，要么通过局部注意力与相似度信号选择 token，无法直接衡量当前块（chunk）是否贡献了超出已保留上下文的新信息。为此，我们提出了 DeCoPrune，一种将缓存压缩视为去噪一致性问题的免训练方法。我们通过实证发现，去噪难度为评估 token 的长期保留价值提供了一个有效的代理指标：具有较大单步与最终去噪结果差异（step-to-final discrepancy）的 token，往往携带了难以从保留上下文中预测的视觉证据。DeCoPrune 利用当前块中每个 token 的中间干净预测值与最终去噪值之间的差异来衡量其去噪难度，在长期缓存中保留高差异的 token，同时剪枝低差异的 token。为了评估信息保留能力，我们提出了基准测试 CMBench，包含 58 个时长约一分钟的生成或真实场景上下文片段，以及 116 个要求召回此前观察到的特定物体或场景的重现（Reappear）或重访（Revisit）续写任务。在 LingBot World v2 上的实验表明，DeCoPrune 在剪枝超过 85% 的历史 KV token 并将续写生成加速 4 倍以上的的同时，保持了接近 FullKV 的长程召回能力，在相当的资源预算下显著优于被评估的压缩基线。这些结果表明，去噪一致性可以作为一种模型内在信号，在降低自回归推理成本的同时保留长程信息。我们的项目主页为 https://decoprune.github.io。代码可从 https://github.com/DeCoPrune/CMBench 获取，基准数据集发布于 https://huggingface.co/datasets/Aoraku/CMBench。

## Abstract
Autoregressive video diffusion supports streaming generation and interactive control, but its KV cache grows continuously with the generated history. Existing compression strategies either discard history using fixed windows or select tokens through local attention and similarity signals, which do not directly measure whether the current chunk contributes information beyond the retained context. We introduce DeCoPrune, a training-free method that treats cache compression as a denoising-consistency problem. We find empirically that denoising difficulty provides a useful proxy for a token's value in long-term retention: tokens with larger step-to-final discrepancies tend to carry visual evidence that is less predictable from the retained context. DeCoPrune measures each current-chunk token's denoising difficulty using the discrepancy between its intermediate clean prediction and final denoised value, retaining high-discrepancy tokens in the long-term cache while pruning those with low discrepancy. To evaluate information retention, we introduce CMBench, comprising 58 approximately one-minute generated or real-world context episodes and 116 Reappear or Revisit continuation tasks that require recalling specific previously observed objects or scenes. Experiments with LingBot World v2 show that DeCoPrune preserves near-FullKV long-range recall while pruning over 85% of historical KV tokens and accelerating continuation generation by over $4\times$, substantially outperforming the evaluated compression baselines at comparable budgets. These results indicate that denoising consistency can serve as a model-intrinsic signal for retaining long-range information while reducing autoregressive inference cost. Our project homepage is https://decoprune.github.io. The code is available at https://github.com/DeCoPrune/CMBench, and the benchmark at https://huggingface.co/datasets/Aoraku/CMBench.

DeCoPrune 是一种**免训练（Training-free）**的自回归视频扩散模型 KV 缓存动态剪枝方法，其核心机制如下：

* **核心思想（去噪一致性与去噪难度）**：
  论文发现“去噪难度”可以作为评估 Token 长期保留价值的有效代理指标。如果一个 Token 在单步去噪过程中的中间干净预测值与其最终去噪结果差异较大（即去噪一致性低），说明该 Token 携带了难以从已有上下文预测的视觉特征（即高信息量），应当予以长期保留。
* **算法流程与技术细节**：
  1. **差异计算（Step-to-Final Discrepancy）**：在去噪过程中，计算当前 Chunk 中每个 Token 的中间预测干净值 $\hat{x}_{0,t}$ 与最终去噪输出值 $\hat{x}_{0,0}$ 之间的差异度。

  3. **选择性剪枝**：保留高差异度的 Token 至长期 KV 缓存中，丢弃低差异度（易预测/冗余）的 Token。
