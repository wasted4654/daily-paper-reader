## 摘要
我们介绍了 DiffusionGemma，这是一款实验性的开源权重语言模型，利用离散扩散（discrete diffusion）以极高的速度生成文本。与每次解码一个 token 的方式不同，DiffusionGemma 并行地迭代优化 256 个 token 的块，从而避免了传统自回归（AR）大语言模型的串行解码瓶颈。我们并非从零开始训练，而是通过微调具有 38 亿激活参数和 252 亿总参数的混合专家（MoE）模型 Gemma 4 来获得 DiffusionGemma。我们计算高效的两阶段训练流水线所使用的 token 预算不足初始自回归模型总训练预算的 10%。第一阶段使用有监督微调来教授双向去噪，而第二阶段结合了强化学习与采样器蒸馏，以共同提升生成质量和推理效率。DiffusionGemma 在生成速度与模型能力之间的权衡上建立了新的帕累托前沿（Pareto frontier）。在我们的完整评估套件中，它平均每次前向传播生成约 20 个 token，在单块 NVIDIA H100 GPU 上实现了每秒约 1,500 个输出 token，这显著快于即使采用了最先进投机解码（speculative decoding）的自回归模型。DiffusionGemma 还保留了初始模型对思考模式（thinking mode）、多模态输入和长上下文的支持。尽管进行了扩散微调，它仍具备自回归生成能力且性能仅有轻微下降，这为混合扩散-自回归解码（hybrid diffusion-AR decoding）提供了一条可行路径。

## Abstract
We introduce DiffusionGemma, an experimental open-weight language model that uses discrete diffusion to generate text at exceptionally high speed. Rather than decoding one token at a time, DiffusionGemma iteratively refines blocks of 256 tokens in parallel, avoiding the sequential decoding bottleneck of conventional autoregressive (AR) large language models. Instead of training from scratch, we obtain DiffusionGemma by fine-tuning the mixture-of-experts Gemma 4 model with 3.8B activated and 25.2B total parameters. Our compute-efficient two-stage training pipeline uses fewer than 10% of the starting AR model's total training token budget. The first stage uses supervised fine-tuning to teach bidirectional denoising, while the second stage combines reinforcement learning with sampler distillation to jointly improve generation quality and inference efficiency. DiffusionGemma establishes a new Pareto frontier for the trade-off between generation speed and model capability. Averaged across our full evaluation suite, it generates around 20 tokens per forward pass and achieves roughly 1,500 output tokens per second on a single NVIDIA H100 GPU, which is substantially faster than AR models even with state-of-the-art speculative decoding. DiffusionGemma also retains the starting model's support for thinking mode, multimodal inputs, and long contexts. Despite diffusion fine-tuning, it remains capable of AR generation with only minor performance degradation, suggesting a path toward hybrid diffusion-AR decoding.

*   **核心问题**：传统自回归（AR）大语言模型采用逐个 Token 生成的串行解码方式，受限于显存带宽（Memory-bound），导致推理速度缓慢且计算单元利用率低。
*   **研究动机**：为了打破串行瓶颈，研究团队探索了**离散扩散（Discrete Diffusion）**技术，旨在通过并行优化 Token 块（Block）将推理过程从显存受限转向计算受限（Compute-bound），从而实现超高速生成。
*   **整体含义**：DiffusionGemma 是首个在保持高智能水平（接近顶级 AR 模型）的同时，实现极高推理速度（~1500 TPS）的开源权重扩散语言模型，填补了扩散模型在“高性能-高速度-开源”三角中的空白。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：将文本生成视为一个迭代去噪过程。模型不再是预测下一个 Token，而是同时对一个包含 256 个 Token 的“画布”（Canvas）进行多次迭代优化。
*   **关键技术细节**：
    *   **架构设计**：基于 Gemma 4 26B A4B (MoE) 权重初始化。采用“因果编码器（Causal Encoder）+ 双向解码器（Bidirectional Decoder）”的组合。编码器处理上下文并维护 KV Cache，解码器在画布内进行双向注意力去噪。
    *   **两阶段训练流水线**：
        1.  **监督微调 (SFT)**：教模型如何在给定噪声的情况下，利用双向注意力恢复原始文本。
        2.  **采样器蒸馏与强化学习 (SD·RL)**：这是核心创新。通过在线学习同时最大化奖励（提升质量）并压缩去噪步数（提升速度）。
    *   **采样算法**：采用**熵限制采样（Entropy-bounded Sampler）**，结合温度退火和**自适应停止（Adaptive Stopping）**机制。当模型对当前块的预测趋于稳定且熵值低于阈值时，提前结束迭代。

### 6. 主要结论与发现
*   **速度突破**：在单块 H100 上达到约 **1500 TPS**，比原版 AR 模型快 7 倍以上，比最先进的 MTP 投机解码快约 5 倍。
*   **效率提升**：平均每次前向传播可生成约 20 个有效 Token（TPF=20），平均仅需 12 次迭代即可完成 256 个 Token 的去噪。
*   **能力保留**：成功继承了 Gemma 4 的“思考模式”、长文本处理和多模态能力，且依然保留了切换回 AR 解码模式的能力。
*   **SD·RL 的关键性**：证明了强化学习不仅能提升模型智能，还能通过降低预测熵来显著加速推理。

### 7. 优点
*   **极致推理性能**：打破了 LLM 推理的延迟瓶颈，非常适合对实时性要求极高的应用。
*   **双向推理能力**：扩散机制允许模型在生成过程中进行“自我修正”和双向上下文参考，在处理结构化数据（如 JSON、代码调试）时表现优异。
*   **自适应计算**：模型能根据任务难度自动调整计算量（简单任务步数少，复杂任务步数多）。
*   **开源友好**：以 Apache 2.0 协议发布，并提供了完整的微调工具包。

### 8. 不足与局限
*   **绝对性能损失**：相比于原始 AR 基准模型，扩散微调后的模型在某些复杂推理任务上存在轻微的性能下降。
*   **生成长度偏短**：SD·RL 训练倾向于让模型生成更简洁的回答，这虽然加速了推理，但可能限制了长篇大论的发挥。
*   **偶发性缺陷**：在极低步数推理时，偶尔会出现 Token 重复（Stuttering）或多模态任务中漏掉结束标签的情况。
*   **高并发瓶颈**：当 Batch Size 超过 32 时，由于单次前向传播计算量大，其吞吐量优势会逐渐被 AR 模型赶超。
