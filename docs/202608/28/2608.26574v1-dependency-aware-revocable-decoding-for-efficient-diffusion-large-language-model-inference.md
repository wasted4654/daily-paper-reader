## 摘要
扩散大语言模型 (dLLM) 通过迭代去噪并行解码多个 token，为自回归生成提供了一种极具前景的替代方案。然而，增加解码并行度通常会降低生成质量，因为早期错误可能会污染后续上下文。可撤销解码通过重新评估已解码的 token 并重新掩码不可靠的 token 来缓解这一问题，但现有方法忽略了不可靠的 token 同样可能破坏验证上下文本身。我们识别出了这种失效模式，并提出了依赖感知可撤销解码 (DARD)，这是一种无需训练的框架，它将 token 分为掩码、候选和非掩码状态。DARD 使用选择性上下文来验证候选 token，该上下文排除了可靠性较低的 token，并自适应地调节它们对后续解码的影响。在 3 个开源 dLLM 上进行的 12 个文本和多模态基准测试实验表明，DARD 在速度-质量帕累托前沿上始终优于近期的可撤销解码方法，在 Flickr30K 数据集上相比 Saber 实现了 2.71 倍的加速和 4.35 点的 CIDEr 分数提升。

## Abstract
Diffusion large language models (dLLMs) offer a promising alternative to autoregressive generation by decoding multiple tokens in parallel through iterative denoising. However, increasing decoding parallelism often degrades generation quality, as early errors can contaminate later contexts. Revocable decoding mitigates this issue by re-evaluating decoded tokens and remasking unreliable ones, but existing methods overlook that unreliable tokens may also corrupt the verification context itself. We identify this failure mode and propose Dependency-Aware Revocable Decoding (DARD), a training-free framework that separates tokens into masked, candidate, and unmasked states. DARD verifies candidate tokens using a selective context that excludes less reliable tokens and adaptively regulates their influence on subsequent decoding. Experiments across 12 textual and multimodal benchmarks on 3 open-source dLLMs show that DARD consistently improves the speed-quality Pareto frontier over recent revocable decoding methods, achieving a 2.71$\times$ speedup and a 4.35-point CIDEr score gain over Saber on Flickr30K.

### 1. 核心问题与整体含义（研究动机和背景）
* **核心问题**：扩散大语言模型（dLLMs）通过并行解码多个 token 来提高推理速度，但高并行度往往会导致生成质量急剧下降。这是因为在同一步骤中并行预测的 token 之间缺乏相互依赖性，容易产生局部合理但整体冲突的错误（例如，同时预测出“Los”和“Diego”，组合成错误的“Los Diego”）。
* **现有方法的缺陷**：现有的“可撤销解码”方法（如 Saber 和 WINO）虽然允许重新评估并撤销（重新掩码）不可靠的 token，但它们在验证某个 token 时，会将其他同样不可靠的已解码 token 作为上下文。这种**验证上下文的污染**会导致错误的验证决策（例如，由于上下文错误而错误地撤销了原本正确的 token，或者无法纠正冲突）。
* **整体含义**：本文提出了 **DARD（Dependency-Aware Revocable Decoding，依赖感知可撤销解码）** 框架。其核心意义在于，通过在验证过程中显式隔离和控制不同可靠性 token 之间的依赖关系，避免了不可靠 token 对验证上下文的污染，从而在不进行任何额外训练的情况下，显著优化了 dLLM 推理的速度与质量平衡（即帕累托前沿）。

### 2. 方法论
DARD 是一种**无需训练（Training-free）**的推理期解码框架，其核心设计包含以下几个关键部分：

* **三态标记管理（Three Token States）**：
  将序列中的位置划分为三种状态：
  1. **掩码状态 ($M$)**：尚未解码的 token。
  2. **候选状态 ($C$)**：已解码但置信度处于中等水平、需要进一步验证的 token（置信度在 $\tau_c$ 和 $\tau_u$ 之间）。
  3. **非掩码状态 ($U$)**：已解码且高度可靠的 token（置信度大于 $\tau_u$）。

* **状态特定的验证与置信度排序注意力机制**：
  为了防止 $C$ 状态中的不确定 token 污染验证上下文，DARD 设计了特殊的注意力掩码：
  * **验证 $U$ 标记**：仅允许其关注其他已确定的 $U$ 标记，完全屏蔽 $C$ 标记。
  * **验证 $C$ 标记**：引入**基于置信度排序的注意力掩码**。$C$ 标记只能关注 $U$ 标记以及比自身置信度更高的 $C$ 标记。这模拟了“置信度高的 token 先解码并作为后续 token 上下文”的自回归过程。

* **自适应对数混合（Adaptive Logit Mixing）预测 $M$ 标记**：
  为了预测新的 $M$ 标记，模型同时生成两条路径：一条包含 $C$ 标记作为上下文（原始序列 $x_t$），另一条将 $C$ 标记视为掩码（影子序列 $s_t$）。
  DARD 根据 $C$ 标记在当前步骤的验证结果（晋升为 $U$ 或降级为 $M$），利用距离加权几何核函数动态计算混合权重 $w_i^t$。若邻近的 $C$ 标记多被保留，则调高包含 $C$ 上下文的预测权重；反之则调低，从而自适应地控制不确定上下文的影响。

### 7. 优点
* **直击现有方法痛点**：首次指出并解决了可撤销解码中“不可靠上下文污染验证过程”这一被忽视的失效模式。
* **无需训练、即插即用**：作为纯推理期算法，不需要对原模型进行任何微调，极易部署到现有的原生或转换后的 dLLM 中。
* **优雅的注意力掩码设计**：巧妙利用影子序列（Shadow Sequence）和块解码（Block Decoding）机制，在单个前向传播中并行完成了状态特定的预测与验证，计算开销增加极低。

---

### 8. 不足与局限
* **绝对性能提升幅度有限**：由于 DARD 并不改变模型本身的概率分布，其本质是提升序列一致性，因此在某些极其复杂的推理任务上，其绝对准确率的提升空间受限于基座模型本身的能力。
* **单步计算开销略有增加**：引入影子序列和复杂的注意力掩码使得单步前向传播的延迟略高于 Saber（但由于总解码步数显著减少，端到端总时间依然更短）。
* **超参数敏感性**：虽然论文表明默认参数在多数任务上表现良好，但阈值 $\tau_c$ 和 $\tau_u$ 的选择仍会在一定程度上影响速度与质量的侧重，针对极特定任务可能仍需微调。
