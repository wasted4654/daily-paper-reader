## 摘要
扩散语言模型 (DLMs) 缓解了自回归 (AR) 大语言模型 (LLMs) 固有的延迟瓶颈，但其生成质量的下降限制了实际应用。尽管知识蒸馏 (KD) 是提高性能的一个有前景的方向，但我们通过实验发现，简单地应用传统 KD 只能获得微小的收益，甚至会降低生成质量。基于这些观察，我们为 DLMs 提出了一种新颖的自蒸馏框架，即 SelFusion。为了在没有外部教师模型的情况下实现有效的 KD，SelFusion 执行两次具有不同掩码级别的前向传递，将掩码概率较大的定义为“困难模式”，将掩码概率较小的定义为“简单模式”。然而，简单模式并不总是比困难模式更准确，并且可能对错误的 token 表现出过度自信。因此，我们在两种模式之间引入了双向 KD，它可以根据 token 级别的正确性动态确定蒸馏方向。在指令遵循任务上的实验结果表明，所提出的自蒸馏方法显著优于使用外部 LLM 和 DLM 教师的其他 KD 方法。在许多配置下，使用 SelFusion 训练的学生模型甚至超过了 LLM 教师的性能，为提高 DLM 生成质量提供了一条切实可行的路径。源代码可在 https://github.com/scai-research/SelFusion_official 找到。

## Abstract
Diffusion language models (DLMs) alleviate the inherent latency bottleneck of autoregressive (AR) large language models (LLMs), but their degraded generation quality limits practical applicability. Although knowledge distillation (KD) can be a promising direction for improving performance, we empirically find that naively applying conventional KD yields only marginal gains, or even degrades generation quality. Based on these observations, we propose a novel self-distillation framework for DLMs, namely SelFusion. To enable effective KD without an external teacher model, SelFusion performs two forward passes with different masking levels, defining the hard mode with a larger masking probability and the easy mode with a smaller masking probability. However, the easy mode is not always more accurate than the hard mode and can be overconfident on incorrect tokens. Thus, we introduce bidirectional KD between the two modes, which can dynamically determine the distillation direction based on token-level correctness. Experimental results on instruction-following tasks show that the proposed self-distillation substantially outperforms other KD methods with external LLM and DLM teachers. In many configurations, the student trained with SelFusion even surpasses the performance of the LLM teacher, providing a practical path toward improving DLM generation quality. Source code can be found at https://github.com/scai-research/SelFusion_official

### 论文总结：SelFusion - 扩散语言模型的自蒸馏框架

#### 1. 核心问题与整体含义
扩散语言模型（DLMs）通过并行解码机制显著缓解了自回归（AR）大语言模型（LLMs）的推理延迟瓶颈。然而，由于其非自回归的特性，DLMs 的生成质量通常远逊于 LLMs。传统的知识蒸馏（KD）在提升 DLMs 性能时面临两大挑战：
*   **分布不匹配**：AR 教师模型的预测分布极其尖锐（Top-1 接近 100%），而 DLM 学生模型的分布相对平坦，导致 Logit 级别的蒸馏效果极差。
*   **缺乏高质量教师**：现有的 DLM 教师模型自身生成质量有限，无法提供有效的监督信号。
**SelFusion** 的提出旨在通过“自蒸馏”机制，在无需外部教师模型的情况下，利用模型自身的内部逻辑提升生成质量。

#### 2. 方法论
SelFusion 的核心思想是利用扩散模型的噪声过程，在单个模型中构建两种前向传播模式，并进行动态互学。
*   **双模式设计**：
    *   **简单模式（Easy Mode）**：采用较低的掩码比例（Masking Ratio），模型可见上下文更多，预测更准确。
    *   **困难模式（Hard Mode）**：采用较高的掩码比例，模拟标准的扩散生成过程。
*   **双向知识蒸馏（Bidirectional KD）**：
    *   不同于传统的单向蒸馏（简单教困难），SelFusion 根据 Token 级别的预测正确性动态决定蒸馏方向。
    *   如果简单模式预测正确而困难模式错误，则简单教困难；反之亦然。若两者都错，则由对 Ground-truth 概率更高的模式担任教师。
*   **RMSNorm 逻辑校准**：
    *   简单模式由于可见上下文多，容易对错误 Token 产生“过度自信”。
    *   研究者在简单模式的 LM Head 前引入了仅含 1,280 个参数的 RMSNorm 层，有效抑制了错误预测的置信度，确保蒸馏信号的可靠性。
*   **损失函数**：总损失由困难模式扩散损失、简单模式扩散损失以及基于 KL 散度的双向蒸馏损失（$L_{bkd}$）组成。

*   **对比方法**：
    *   **SFT（监督微调）**：包括 LLM 教师和 DLM 学生基准。

*   **实验规模**：论文在 6 个不同的评估数据集上进行了测试，并针对 8 步、16 步和 32 步不同的扩散推理步数进行了验证。
*   **消融实验**：详细探讨了双向蒸馏的必要性（对比了单向蒸馏）、RMSNorm 的校准效果、以及不同掩码比例对概率分布的影响。
*   **客观性**：每个基准测试均使用 3 个随机种子取平均值，并对比了推理延迟（Latency）与加速比。实验设计全面，涵盖了性能、效率、泛化性及底层原理分析，论证较为充分。

#### 6. 主要结论与发现
*   **性能超越教师**：SelFusion 训练的学生模型在多个基准测试中不仅超过了所有 KD 基线，甚至在某些任务（如 Self-inst, Vicuna）上超越了规模更大的 LLM 教师模型。
*   **自蒸馏的优越性**：在 DLM 领域，自蒸馏比引入外部 AR 教师更有效，因为它避免了严重的分布错位问题。
*   **动态方向的重要性**：实验证明简单模式并非在所有 Token 上都优于困难模式，双向动态蒸馏是性能提升的关键。

#### 7. 优点
*   **无需外部教师**：极大地简化了蒸馏流程，降低了对高性能大模型 API 或权重的依赖。
*   **即插即用**：仅需极少量的额外参数（RMSNorm）即可实现显著的性能提升。
*   **理论支撑扎实**：对 DLM 与 AR 模型之间的分布差异进行了深入分析，并针对性地提出了校准方案。

*   **骨干网络受限**：由于目前开源的高质量 DLM 骨干网络较少，实验主要集中在 SMDM 架构上，缺乏在更多样化架构（如连续扩散模型）上的验证。
