## 摘要
室内三维场景图（3DSG）将环境表示为多层层级结构，连接观测到的几何基元（如平面）与更高层级的度量-语义概念（如房间、楼层、建筑），从而为机器人感知与 SLAM 提供增量式空间推理能力。然而，传统的高层概念生成方法依赖于针对特定概念类别的手工设计规则，而基于学习的方法则需要为图结构和空间节点特征（如质心）分别建立模型，这限制了其向新类别及更复杂层级结构的扩展能力。我们提出了一种统一的基于自回归扩散的图生成模型，该模型可联合学习结构与特征，从观测到的垂直平面自底向上构建任意层级深度的完整 3DSG。在涵盖合成场景、真实建筑平面图以及机器人传感器数据（包含不同的布局复杂度和层级深度）的 3DSG 数据集上，我们的方法持续超越所有基于学习和随机的基线方法，并且在最大层级结构和真实单层数据上超越了拥有目标图尺寸先知信息（oracle access）的单次（one-shot）模型。最后，我们调整并引入了融合 Gromov-Wasserstein 距离，实现了生成的 3DSG 与真实值之间原则性的图级别评估。

## Abstract
Indoor 3D Scene Graphs (3DSGs) represent environments as multi-layer hierarchies that connect observed geometric primitives (e.g., planes) to higher-level metric-semantic concepts (e.g., rooms, floors, buildings), enabling incremental spatial reasoning for robotic perception and SLAM. However, classical high-level concept generation approaches rely on hand-crafted rules for specific concept classes, while learning-based methods require separate models for graph structure and spatial node features (e.g., centroids), which limits scalability to novel classes and more complex hierarchies. We propose a unified autoregressive diffusion-based graph generative model that jointly learns structure and features, constructing complete 3DSGs bottom-up from observed vertical planes across arbitrary hierarchy depths. Our method consistently surpasses all learning-based and random baselines across 3DSG datasets spanning synthetic scenes, real architectural floor plans, and robotic sensor data, with varying layout complexity and hierarchy depth, and surpasses a one-shot model with oracle access to the target graph size on the largest hierarchy and on real single-floor data. Finally, we propose an adaptation of the Fused Gromov--Wasserstein distance for principled graph-level evaluation of generated 3DSGs against ground truth.

### 2. 核心方法论

论文提出了一种基于**自回归扩散**（Autoregressive Diffusion）的图生成框架，将场景图的延伸建模为逐块增加节点和边的过程。

#### 核心架构与关键模块
1.  **平面图初始化**：将机器人建图（如 S-Graphs+）提取的垂直 3D 平面作为起始节点，利用 k-NN 基于欧氏距离连接近邻平面，提供初始图拓扑语义上下文。
2.  **自回归生成主框架（FLAGG）**：
    *   **插入模块（Insert Module）**：采用 GINE 预测当前步骤需要新增的节点块大小 $m_t$。
    *   **填充模块（Fill Module）**：在给定已生成图 $G_{t-1}$ 的条件下，一步生成新节点块的标签、内部/跨块边连接及 3D 质心。
    *   **停止模块（Halt Module）**：预测二分类信号 $H_t$，判断图生成是否完成。
3.  **两种填充模块变体（Fill Module Variants）**：
    *   **`OURS-FD4`（因子化 D4 扩散模型）**：将生成解耦为两阶段。先用 DiGress（离散扩散模型）生成标签与边拓扑；再通过高斯扩散预测新边上的 pairwise 3D 距离；最后通过**多维缩放（MDS）**解算出 3D 质心坐标。
    *   **`OURS-MIDI`（MiDi 联合扩散模型）**：在中心化坐标系下，利用图 Transformer 联合对离散变量（标签、边）与连续变量（3D 坐标）进行一步式去噪扩散。
4.  **关键优化技巧**：
    *   **层次化顺序（Hierarchical Ordering, H & HP）**：在训练阶段定义自底向上的节点节点消除/插入顺序（平面 $\rightarrow$ 墙 $\rightarrow$ 房间 $\rightarrow$ 楼层 $\rightarrow$ 建筑 $\rightarrow$ 城市），HP 进一步结合空间邻近度，指导生成过程由内向外扩展。
    *   **噪声增强（Noise Augmentation）**：训练时对历史生成节点添加标签扰动、高斯位置噪声及随机落边/加边，缓解自回归推断时的曝光偏差（Exposure Bias）。
5.  **评估指标创新（ adapted FGW 距离）**：
    *   引入**融合 Gromov-Wasserstein 距离（FGW）**，结合衡量节点属性/语义/坐标差异的 Wasserstein 距离（W）与衡量拓扑结构/最短路径差异的 Gromov-Wasserstein 距离（GW），实现图与图之间客观看准的 1-to-1 匹配评估。

### 3. 实验设计与 Benchmark

#### 数据集与场景
作者构建并开源了一个包含 **9 个子集** 的多层 3DSG Benchmark，数据来源于三大场景：
1.  **Synthetic (S)**：合成场景，包含矩形房间（S-F-□）、任意形状房间（S-F）以及包含城市级深度的高层场景（S-C）。
2.  **MSD (M)**：基于真实建筑平面图的数据集，包含楼层级（M-F）、建筑级（M-B）、城市级（M-C），结构更为复杂庞大。
3.  **Real (R)**：机器人实测 LiDAR SLAM 数据，包含单楼层（R-F）、多楼层（R-B）和多建筑（R-C）真机测试场景。

#### 对比基线（Baselines）
*   **`RAND`**：根据训练集先验统计分布随机采样节点数、标签和边的基线。
*   **`EC-□`**（Millan-Romera et al., 2024）：基于双 GAT 边分类+聚类的方法，仅支持矩形房间，无质心预测，仅支持 2 层。
*   **`EC-L`**（Millan-Romera et al., 2025）：基于单 GAT 边分类+社区检测的方法，无质心预测，仅支持 2 层。
*   **`MIDI+OR`**：将 SOTA 单次图生成模型 MiDi 适配为条件补全模型，并给予其**目标图尺寸的 Oracle 先验信息**（特权基线）。

#### 评估指标
*   **图匹配指标**：FGW（综合距离）、GW（结构距离）、W（特征与位置距离）。
*   **分布相似度指标（MMD）**：度分布（Deg.）、光谱距离（Spec.）、聚类系数（Clust.）、GIN 隐空间特征距离（GIN）。

### 6. 论文的主要结论与发现

1.  **全面超越非特权基线**：在所有数据集（合成、MSD、真实机器人数据）上，`OURS-FD4` 和 `OURS-MIDI` 在 FGW、GW、W 以及结构分布指标上均显著优于 `EC-□`、`EC-L` 和 `RAND`。
    *   在矩形合成场景中，FGW 误差比 `EC-L` 降低了 50%。
    *   在复杂的真实平面图数据（M-F）中，FGW 误差比 `EC-L` 降低了 65%。
2.  **在大规模/分布外场景下击败 Oracle 单次模型**：
    *   在最大的场景（M-C 城市级）和实测单层场景（R-F）中，`OURS-FD4` 的表现超越了拥有先知节点的单次模型 `MIDI+OR`（如 M-C 上 FGW 0.20 vs 0.28）。
    *   证明自回归预测图尺寸比直接利用经验分布采样或依赖固定先知在复杂场景下更具泛化力。
3.  **填充模块的泛化力差异**：
    *   `OURS-MIDI` 在同分布的 MSD 楼层/建筑数据上得分略优；
    *   `OURS-FD4` 基于 pairwise 距离+MDS 的生成机制在**分布外（Out-of-Distribution, 如真机实测数据 R-B）表现出更强的鲁棒性**。

### 8. 局限性与潜在不足

1.  **自回归推断的计算开销与推理时延**：由于模型采用了自回归与去噪扩散相结合的生成机制，在处理节点数较多的庞大场景（如跨楼层或城市级）时，推理耗时会显著增加，难以做到微秒级的实时在线更新。
2.  **对前端平面提取质量的依赖**：该框架将底层 3D 垂直平面作为自底向上生成的起点（依赖 S-Graphs+ 等 SLAM 前端提取）。若底层几何感知模块存在噪声、平面缺失或分割错误，这些误差可能传播至高层节点的生成中。
3.  **MDS 对距离预测误差的敏感性（针对 `FD4` 变体）**：`OURS-FD4` 依赖 pairwise 距离预测并通过多维缩放（MDS）解算 3D 质心。当预测的边距离矩阵存在局部扰动时，MDS 可能导致全局 3D 几何坐标产生整体偏移或扭曲。
4.  **算力门槛较高**：在大规模数据（MSD 建筑/城市级）训练时，需要依赖高性能 GPU（如 A40），在计算资源受限的边缘端（如板载机器人平台）部署仍面临挑战。

### 9. 启示与未来研究方向

1.  **端到端 SLAM-3DSG 实时集成**：未来可尝试将该自回归扩散图生成器直接集成为增量式 SLAM 系统的高级感知后端，实现从传感器点云/RGB-D 帧到深层 3DSG 的实时在线演化。
2.  **引入常识先验（结合 VLM/LLM）**：利用大语言模型（LLM）或视觉语言模型（VLM）所蕴含的开放世界空间与语义常识，指导扩散过程的节点/边预测，以进一步增强在分布外（OOD）及未曾见的极端复杂环境下的泛化能力。
3.  **扩散模型采样加速**：引入一致性模型（Consistency Models）、蒸馏技术（Distillation）或隐空间图扩散（Latent Graph Diffusion），以减少去噪采样步数，解决自回归生成的推断瓶颈。
4.  **下游具身智能任务验证**：将生成的深层层次化 3DSG 投入到实际具身智能（Embodied AI）任务中，例如长程层次化路径规划（Hierarchical Path Planning）、跨楼层语义导航（Cross-floor Navigation）及自然语言导向的对象搜寻。
