## 摘要
大语言模型（LLM）的成功很大程度上归功于下一个 Token 预测（NTP），但其自回归（AR）结构需要缓慢的顺序 Token 生成。为了克服这一瓶颈，我们引入了扩散增强型 LLM，这是一类新的模型，它在定义 AR 模型分布的同时，利用扩散过程从该分布中并行抽取多个 Token。我们将这些模型的参数解耦为两组：使用标准 NTP 目标训练的 AR 权重，以及用于同时生成多个 Token 的轻量级扩散权重。扩散权重是通过一个简单的扩散蒸馏（Diffusion Distillation）阶段学习得到的，该阶段对现有 LLM 训练流程增加的开销微乎其微。我们还引入了 $Ψ$-Spec，这是一族能在固定上下文长度下实现无损加速和推理期扩展（inference-time scaling）的采样器。与投机解码（speculative decoding）不同，我们的方法不需要独立的草稿模型；与扩散 LLM（d-LLM）不同，它在加速生成的同时不会牺牲底层 AR 模型的质量。由此产生的模型被称为 Uno，既可以从头开始训练，也可以通过增强现有的开源权重 AR LLM 来构建。Uno 在所有评估的批次大小下都取得了比领先的投机解码方法更高的吞吐量，相比基础 AR 模型实现了高达 $3\times$ 的加速，包括在设备支持的最大批次大小下。值得注意的是，在智能体工具使用、代码生成和长上下文推理的所有评估基准上，我们的 8B Uno 模型均超越了领先的开源 d-LLM（26B 的 DiffusionGemma）以及闭源的 Mercury 2。我们在 https://s-sahoo.github.io/uno/ 开源了代码和模型权重。

## Abstract
Large Language Models (LLMs) owe much of their success to next-token prediction (NTP), but their autoregressive (AR) structure requires slow, sequential token generation. To overcome this bottleneck, we introduce diffusion-augmented LLMs, a new class of models that defines an AR model distribution while using diffusion to draw multiple tokens in parallel from that distribution. We decouple the parameters of these models into two sets: AR weights, trained using the standard NTP objective, and lightweight diffusion weights, trained to generate multiple tokens simultaneously. The diffusion weights are learned through a simple Diffusion Distillation phase that adds negligible overhead to existing LLM training pipelines. We also introduce $Ψ$-Spec, a family of samplers that enables lossless acceleration and inference-time scaling at a fixed context length. Unlike speculative decoding, our method requires no separate draft model. Unlike diffusion LLMs (d-LLMs), it accelerates generation without sacrificing the quality of the underlying AR model. The resulting models, called Uno, can be trained from scratch or built by augmenting existing open-weight AR LLMs. Uno achieves higher throughput than leading speculative-decoding methods at every evaluated batch size and delivers up to $3\times$ speedups over the base AR model, including at the largest batch size supported by the device. Notably, our 8B Uno model outperforms the leading open d-LLM, the 26B DiffusionGemma, and the proprietary Mercury 2 across all evaluated benchmarks in agentic tool use, coding, and long-context reasoning. We release code and checkpoints at: https://s-sahoo.github.io/uno/

### 1. 研究动机与背景（核心问题）
* **核心瓶颈**：当前大语言模型（LLM）依赖“下一个 Token 预测”（NTP）自回归（AR）机制，必须逐个生成 Token。这种串行解码模式在推理期（尤其是长文本推理和强化学习 RL 的 Rollout 阶段）极易受到内存带宽限制（Memory-bound），导致 GPU 计算资源严重浪费、生成速度缓慢。
* **现有方法的局限**：
  * **投机解码（Speculative Decoding）**：依赖独立的轻量级草稿模型（Draft Model），需要维护两套独立的 KV Cache，增加了额外的内存开销和模型对齐成本。
  * **离散扩散 LLM（d-LLM）**：虽然支持原生并行生成，但生成质量相比 AR 模型有所下降（有损加速），且在**大 Batch Size（高并发服务）** 下的速度优势会迅速消失。
* **核心目标**：解耦 LLM 的“生成质量”与“生成速度”，在**完全不损害基座 AR 模型生成质量（无损，Lossless）**的前提下，无需独立草稿模型，且在**所有 Batch Size（包括最大硬件并发）** 下均能实现显著的并行加速。

### 2. 核心方法论（Uno & $\Psi$-Spec 采样器）

#### 核心思想
提出**扩散增强型 LLM（Diffusion-Augmented LLMs，命名为 Uno）**。在单一模型架构内融合两套解耦的参数：
1. **自回归权重 ($\theta_{\text{AR}}$)**：决定输出质量，按标准 NTP / SFT / RL 流程训练并冻结。
2. **扩散权重 ($\theta_\Delta$)**：仅用于并行草稿生成，以轻量级 LoRA 适配器形式附加在 AR 层上。

#### 关键技术细节与训练流程
1. **极轻量训练（Diffusion Distillation Phase）**：
   * 冻结 AR 主干权重 $\theta_{\text{AR}}$，仅训练 LoRA 扩散权重 $\theta_\Delta$。
   * **单步块蒸馏（One-step Block Diffusion）**：将文本序列划分为长度为 $B$ 的块（Block），利用带有 Gated LoRA 的块因果注意力掩码，在一步蒸馏中让扩散路径直接拟合 AR 模型在对应块上的输出分布。
   * **复合损失函数**：结合了离散一致性蒸馏损失（$\mathcal{L}_{\text{DCD}}$）与全变差损失（$\mathcal{L}_{\text{TV}}$），旨在显式提高被 AR 验证器接收的连续 Token 长度。
2. **$\Psi$-Spec 采样算法（无损推理）**：
   * **Draft 阶段**：同时激活 $\theta_{\text{AR}} + \theta_\Delta$，通过 1 次扩散前向传播并行生成 $B$ 个 Token 的候选草稿（支持 Linear 线性采样或 Tree 树状采样）。
   * **Verify 阶段**：仅激活 $\theta_{\text{AR}}$，通过一次前向传播对草稿进行拒绝采样（Rejection Sampling），接受最长有效前缀，并由 AR 模型补充采样下一个 Token。
   * **共享 KV Cache**：草稿与验证在同一模型中完成，共享 KV Cache，大幅降低显存峰值占用。

### 6. 主要结论与发现

1. **绝对无损的高加速比**：Uno 在单用户低延迟场景（Batch Size = 1）下实现 **2.2× ~ 3×** 的加速；在设备极限 Batch Size（高并发服务）下，仍保持 **1.5× ~ 2×** 的加速比。
2. **全面超越同类投机解码**：Uno 在所有并发批次大小下，系统吞吐量均严格 Pareto 优于 EAGLE-3 和 DFlash，且显存峰值更低（共享 KV Cache）。
3. **击败主流扩散 LLM**：8B 的 Uno 模型在智能体工具使用、代码生成及长文本推理上，**性能全面超越 26B 的 DiffusionGemma 以及闭源的 Mercury 2**，同时系统吞吐量达到 Mercury 2 的 **4.6×**。
4. **赋能 RL 训练加速**：在 SFT 后冻结扩散适配器、仅对 AR 权重进行 RL 强化学习（如 DAPO），Rollout 阶段可获得高达 **40% 的端到端训练加速**，且蒸馏适配器的接受率仅出现约 6% 的微小衰减。

### 7. 方法与实验亮点（优点）

* **架构优雅**：打破了“独立草稿模型”和“修改 AR 原生参数”的传统路线，巧妙利用内嵌的 Gated-LoRA 实现了“一套主干、双向路径（AR 验证 + 扩散草稿）”，极大地节省了显存和维护成本。
* **解决 d-LLM 的并发痛点**：传统 d-LLM 在 Batch Size 增大时加速比会消失甚至慢于 AR，而 Uno 成功将无损加速拓展到了高并发吞吐场景。
* **极低的蒸馏门槛**：只需不到 15B Token 的训练量和数十小时 GPU 开销，即可为现有的开源 AR 模型（如 Qwen）注入扩散加速能力。

---

### 8. 不足与局限

* **理论 TPF 上限受限**：由于一个生成循环需要 1 次 Draft 前向传播 + 1 次 Verify 前向传播（共 2 次 Pass），理论上的最高 Token/Pass 上限为 $(B+1)/2$。
* **草稿质量依赖分布对齐**：若草稿 LoRA 适配器在某些极罕见领域与 AR 目标分布产生偏移，接受率下降会导致加速效果打折扣。
* **单 Pass 融合算子尚未开发**：目前草稿与验证仍分两次前向传播完成，论文提及可通过二次采样（Quadratic Samplers）融合成单次前向传播，但尚留待后续高效 CUDA Kernel 的开发。
